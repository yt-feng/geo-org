# tokvilo：积分与预算体验（2026-10-26）

## 研究依据与产品推论

Thaler 的心理账户研究把用户的财务认知分为结果评价、用途分类和账户检查频率。预算标签能帮助组织和跟踪支出。对 tokvilo 的产品推论是：用“API 预算”组织余额，以可理解的任务成本辅助选择，而不把积分当作更便宜的货币。[原论文：Mental accounting matters](https://onlinelibrary.wiley.com/doi/10.1002/%28SICI%291099-0771%28199909%2912%3A3%3C183%3A%3AAID-BDM318%3E3.0.CO%3B2-F)

一项覆盖三万多位消费者的线上电影票实验发现，隐藏附加费增加了加入购物车，也增加了最终结账放弃；该实验中整体需求未随展示方式改变。这不证明 tokvilo 的转换率结果，但说明不能把“减少价格可见性”当作稳定提升成交的方法。[原论文：To buy or not to buy?](https://doi.org/10.1016/j.euroecorev.2020.103593)

分拆价格实验还发现：对于被认为较不可信的卖方，不显示总价且拆出更多项目，会损害公平性感知与购买意愿。因此实际金额、计费单位和确认后的总额保持可见，附加信息使用统一详情入口。[原论文：Examining differences in consumer reactions to partitioned prices](https://doi.org/10.1016/j.jbusres.2007.09.005)

以上是研究依据与设计推论，不能替代本站实验，也不承诺销售提升。

## 本次实现

- 固定 USD 1 = 1,000 tokvilo API 积分；0.001 积分精确对应 1 微美元。
- 同一余额同时显示积分和美元等值。充值的实际现金价格仍清楚显示；税费不增加积分。
- 价格页提供预算试算器。每个样本使用 2,000 输入 + 1,000 输出 tokens，选择同一服务、匹配档位的当前普通文本费率，合计一次取整后计算预算可负担的样本数量。不计入工具等附加项目，不承诺调用次数。
- 预算输入仅用于试算，不设置后台限额，不自动充值或发起请求。未开通、缺少完整输入输出费率或条件不明的价格不参与试算。
- 主卡片保留真实售价、单位及上下文条件；所有型号的官方比较统一放在“价格对比与计费说明”，并未删除高价或不可比项目。
- 只有各档位的输入/输出报价成对完整、全部列示费率均已核实更低、且服务已开通时才显示整体节省摘要。混合高低档位或缺失报价不能用局部优惠代表整款模型；“至少”比例向下取到一位小数。
- 钱包区分可用积分、处理中预留和流水；工作台区分报价预留与最终消耗，保留真实 token 数据。
- 中英文同步覆盖首页说明、价格、比较、选型、充值、工作台、博客和服务说明。控制台的“每日请求次数”保持次数，不转换为积分。
- 数字商品人民币售价、历史商品订单和历史商品流水不转换为 API 积分。

## 账务边界

这是显示和预算体验升级。USD 微美元账本、充值金额、支付回调、预留 header、供应商选择和真实 token 用量均不改写。既有余额等值显示，没有增发、扣减、失效或赠送余额。本次也没有把现有零售价自动降至官方九折；是否便宜仍由实际费率和已核实比较决定。

## 验证与后续评估

675 项测试通过，生产构建、TypeScript 与改动文件 ESLint 通过。回归覆盖微美元精度、负数冲回、无效金额、预算次数向下取整、混合高低费率或缺失输入/输出报价不产生整体优惠、未开通服务不参与试算，以及真实支付金额和请求参数不变。改动文件凭据扫描未发现泄露。

最终 Cloudflare Worker 版本为 `ebfc002b-654b-4502-810f-11c89c2b1d54`，于 2026-10-26 发布。首次发布在上传完成后的域名记录查询收到 Cloudflare 10500 错误；随后独立读取部署状态，确认当时版本已承接 100% 流量。最终发布包含输入/输出报价完整性修正，上传和域名触发器部署均成功。中英文价格、支付说明与条款共 6 条线上路径均返回 200，并含固定兑换率说明。

Chrome 实际验证了中英文价格页、预算实时重算、官方比较展开和已登录钱包：相同示例费率下，USD 20 的 3,968 个样本变为 USD 10 的 1,984 个；混合档位的模型未显示整体节省标记，展开后仍显示高于官方的对应费率；钱包积分与美元等值、预留额及 USD 20/50/100 现金包价格一致。本次未新建支付或付费生成请求，亦未完成手机实机验收。

后续可评估价格页到有效报价的转化、报价到成功调用的转化、充值完成率、结账放弃、费用相关咨询与复购。应同时跟踪消费理解和售后反馈；不能仅用点击率判断效果。这些指标是评估建议，本次未新增跟踪代码或声称结果。
